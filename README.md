# Superhero-Vending-Machine
<ul>
  <li>Creation Date: August 5ht, 2026</li>
  <li>Coding Language: Python</li>
  <li>IDE: Visual Studio Code</li>
</ul>

<h2>Features</h2>
<ul>
  <li>One player game</li>
  <li>Allows the user to select a hero plushie from two different array lists. One array list that contains six Marvel superheroes. One array list that contains six DC superheroes.</li>
  <li>Allows users to CREATE THEIR OWN superhero plushie. Attributes include: name, gender, and  elemental superpower (water, fire, earth, air)</li>
  <li>This program contains a main menu feature. The main menu options are: Buy a Marvel Superhero, Buy a DC Superhero Plushie, Create your own Superhero Plushie, Exit</li>
  <li> This program is written in a while loop. This provides the user with the opportunity to choose more than one Marvel superhero, DC superhero, or create more than one custom superhero. </li>
</ul>
